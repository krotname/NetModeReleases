# NetMode — Linux Mobile

NetMode проверяет доступность сайтов и помогает сравнить работу сетевых путей. Этот репозиторий содержит инструкции и готовые пакеты Linux Mobile.

Версия 2.11.0 предназначена для ARM64-телефонов с Phosh. Проверена на OnePlus 6T с Kali Linux 2026.3, экраном 360 логических пикселей и системной Java 25.0.5. Требуется Java 17 или новее.

Приложение включает монитор доступности, категории и собственные сайты, профили и выбор проверок, журнал, статистику, техническую диагностику, сравнение прямого подключения с HTTP/SOCKS5-прокси, уведомления и сохранение отчёта в Downloads. Простой вид показывает состояние сети и одну кнопку проверки, Pro — все настройки по вкладкам и разделам. Экранная клавиатура Phosh открывается по фокусу поля и закрывается по Enter.

Скачайте ARM64 DEB и файл контрольных сумм в [Linux Mobile 2.11.0](https://github.com/krotname/NetModeReleases/releases/tag/linux-mobile-v2.11.0). В каталоге с загруженными файлами выполните:

```sh
sha256sum -c SHA256SUMS-linux-mobile.txt
sudo apt install ./netmode-2.11.0-linux-arm64-mobile.deb
```

Зависимости устанавливаются через APT. При повторной установке другого пакета с той же версией используйте `sudo apt install --reinstall ./netmode-2.11.0-linux-arm64-mobile.deb`. NetMode появляется в меню приложений.

Пакет DEB не подписан; целостность проверяется SHA-256. Опубликованный выпуск неизменяем. Manifest и VERSION.txt внутри установленного приложения фиксируют версию и исходную ревизию.

Результаты относятся к выбранным адресам и времени проверки. Неизвестные VPN, системный proxy или PMTU не считаются успешной проверкой. HTTP/SOCKS5 сам по себе не шифрует соединение до прокси; учётные данные такого прокси требуют доверенного пути. Файл отчёта может содержать IP-адреса и DNS из выполненной диагностики и сохраняется только по действию пользователя.

В 2.11.0 мобильный пакет не предлагает автозапуск из настроек. При временном отказе сервиса уведомлений Bell сохраняет ожидание, но автоматическая повторная отправка не предусмотрена.

Этот канал выпускает только Linux Mobile ARM64; версии других платформ распространяются отдельно. Поддержка: netmode@krot.name.
